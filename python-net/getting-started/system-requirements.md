## General Requirements

- [Python](https://www.python.org/downloads/) 3.5 to 3.14, 64-bit
- pip 20.3 or later
- About 2.2 GB to download and 3.2 GB of disk space for all 14 products

No Microsoft Office, OpenOffice or separately installed .NET runtime is needed: each product ships its own .NET runtime.

## Supported Operating Systems

### Windows

* 64-bit (x64) Windows versions that [.NET 10 supports](https://github.com/dotnet/core/blob/main/release-notes/10.0/supported-os.md)
* 32-bit Windows is not supported

### Linux

* x86_64 with glibc 2.27 or later, for example Ubuntu 18.04, Debian 10 or RHEL 8 and later

### macOS

* macOS 13 or later, on Intel (x86_64) and Apple Silicon (arm64)
* On an Intel Mac whose Python reports macOS 10.16, use pip 24.1 or later

## Additional System Libraries

### Linux

Every product needs ICU, the products that render or measure text need fontconfig and fonts, and several products use `libgdiplus`. To cover all 14 products on Debian-based Linux distributions, install them with [apt-get](https://wiki.debian.org/apt-get):

```bash
sudo apt-get update
sudo apt-get install -y libicu-dev libgdiplus fontconfig ttf-mscorefonts-installer
```

`ttf-mscorefonts-installer` is in Debian's `contrib` component. If apt cannot find it, enable `contrib`, or install `fonts-liberation` instead.

Without ICU, the first call into a product stops the Python process with "Couldn't find a valid ICU package".

### macOS

Several products use `libgdiplus`, which you can install with the [Homebrew](https://brew.sh/) package manager:

```bash
brew install mono-libgdiplus
```

Each product's own system requirements page lists exactly what that product needs.

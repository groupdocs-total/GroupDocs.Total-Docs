Use this page to pick a line. They are not interchangeable, and this Java documentation describes only the on-premise SDK.

## GroupDocs.Total for Java (this documentation)

Choose the on-premise Java SDK when your application calls the library on the JVM.

- Package: `com.groupdocs:groupdocs-total`
- Repository: https://releases.groupdocs.com/java/repo/
- Install: [Installation]({{< ref "total/java/getting-started/installation.md" >}})
- Examples: https://github.com/groupdocs-total/GroupDocs.Total-for-Java

## GroupDocs.Total Cloud

Choose Cloud when you want the hosted line instead of the on-premise JAR. Cloud is a separate product. This repository does not document Cloud APIs.

- https://products.groupdocs.cloud/total

## MCP

Choose MCP when an AI client should call Total tools. The MCP server is not the Java SDK.

- https://github.com/groupdocs-total/GroupDocs.Total.Mcp
